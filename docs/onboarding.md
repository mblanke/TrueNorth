# Onboarding: moved

This page described the August onboarding flow (Request access for everybody, then approval,
then a first-run wizard). Since ADR 0014, a Student on a class **roll call** goes straight in,
and everyone signs the **Rules of use** first. The role guides replace this page:

| You are | Read |
|---|---|
| A Student | [guides/05-student-quick-start.md](guides/05-student-quick-start.md) |
| An instructor (roll call, onboarding emails, seat forfeit) | [guides/04-instructor-guide.md](guides/04-instructor-guide.md) |
| An administrator (bootstrap admin, approvals, roles, tenants, troubleshooting) | [guides/03-admin-first-day.md](guides/03-admin-first-day.md) |

The identity plumbing (Keycloak, AD federation, group → role mapping, roster adoption, MFA,
the AD status sync) is in [identity.md](identity.md).
