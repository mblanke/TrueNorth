**Counts after the amendment.** 49 registered checks (42 + 7), 17 modules. On S: 46
mandatory, 3 permitted skips (all H). Per module: platform-core 8 mandatory (was 5),
ranges-labs 4 mandatory + 1 H (was 3 + 1), provisioners 3 mandatory + 1 H (was 2 + 0),
wiki-helpdesk 2 mandatory (was 1); the other 13 modules are unchanged. The Summary's
"Mandatory checks (S)" and "Permitted skips (S)" columns record the rc4 contract that rc11
was judged against; a candidate built after this amendment is judged against these counts.

**Not covered, and why.** Retention (the purge of exported days) is not exercised: it deletes
data and needs rows older than 30 days, so it stays U (`tests/worker/test_audit_tasks.py`,
`tests/api/test_audit_append_only_postgres.py`); A2 and A3 prove the guard and the export
it depends on. The Students' own credentials view (a participant of a running exercise
reading its `student_visible`, applied accounts) needs a built range (accounts are `applied`
only by a build), so it is H; A4 proves the refusals and the staff view. Security Onion
reconcile (#216) is not on main and is not contracted.

**Finding the check is built to catch (estimate, not observed).** `build.sh replicate`
shortens a host name at its first dot, the provisioner keeps an IPv4 address whole and its
copy-name pattern has no dots: on a vCenter whose hosts are registered by IP address, no
host-local copy would ever be resolved and every clone would copy disks across the network.
A5 FAILs in that case. Whether the work vCenter registers its hosts by name or by address is
not recorded here.
